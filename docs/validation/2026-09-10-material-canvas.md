# 设备与库位画布验收记录

## 范围

正确前端：`Uni-Lab-OS/frontend`。本次修改物料页面及资源使用展示模型，沿用 Python Edge 的物料图和资源使用接口，没有新增业务表或修改物料空间坐标。

入口：物料页 `/console/?page=materials`；任务页“占用资源”仍可进入并筛选对应 Task。

## 展示与操作

- 左侧可搜索物料、设备、库位，右侧为可平移和缩放的画布。
- 设备标题与所属全部库位在同一个容器内，拖动标题左侧手柄整体移动，库位不能单独拖出。方向键也可微调。
- 布局参考已存储的空间位置，组合父级变换并避让重叠。布局不依赖 Task 状态和库存数量，普通刷新不会重排。
- 画布拖动位置以资源 UUID 保存到当前浏览器 localStorage；不调用物料修改、上下料或设备动作接口，不改变资源空间坐标。这一期不提供跨浏览器共享画布排布。
- 库位采用紧凑格子，保留编号、物料名称缩略和占用色；完整信息在悬浮卡片中展示。
- 同一库位分组内不同高度的库位全部同时展示，不再使用层切换。S04 的 6 个库位按 3 列、2 行展示；下属仓、TIP 盒等容器仍通过设备内的库位分组切换。设备块按最大分组的完整行数预留高度，切换分组不移动设备块。
- 设备点亮依据为直接设备占用或正在执行的 Job；库存和单库位预留不会把空闲设备点亮。
- 库位点亮依据为实际存放物料。未绑定 Task 的初始库存仍以青色点亮；Task 物料使用稳定任务色。
- 库位悬浮分别显示当前物料、物料关联 Task、库位使用 Task。物料悬浮显示当前位置和关联 Task。左侧列表同样支持。
- 点击资源打开预览，点击详情进入抽屉，保留物料管理、上下料、Task 和 Trace 入口。
- 删除右上角未接入登录的头像、用户姓名、管理员角色与下拉菜单。
- 接口失败保留最后一次完整快照并标记只读；位置相互矛盾的快照会被拒绝，避免重复显示同一个烧杯。

## 跨设备转运

A 烧杯从设备甲库位 1 到设备乙库位 8：

1. 执行中保留最近确认的实际位置，源库位显示“转移中”，目标显示“待放入”且保持空库位颜色。
2. 实际库存提交后，源库位清空熄灭，目标库位显示 A 烧杯并点亮；物料 Task 绑定跟随该物料。
3. 左侧物料定位、悬浮信息与点击定位同步改为新库位；设备和库位自身布局不变。
4. 结果不确定时显示待确认；不因 Job 进入失败就假定已经到达目标库位。
