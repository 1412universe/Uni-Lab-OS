# 验证记录

本目录保存各次验证的报告、冻结工作流、事件、摘要和截图。每份报告中的日期、版本、环境及验收范围只对应当次运行；历史通过记录不代表当前提交已重新执行全部场景。

版本控制保留可阅读的报告与文本证据。本地 SQLite 数据库快照（`*.db` 及其 WAL/SHM 文件）、原始日志和临时文件由忽略规则排除，已有本地文件不删除。部分历史报告和清单仍记录这些本地产物的路径或摘要；从 Git 克隆仓库不会取得这些文件，需要按对应报告中的运行器重新生成。

2026-09-10 的前端以 `frontend/` 内置控制台为准。旧独立前端的流程核查属于历史记录；当前入口与实现参见 [Edge 错误处置说明](../edge-error-handling-implementation.md)。
