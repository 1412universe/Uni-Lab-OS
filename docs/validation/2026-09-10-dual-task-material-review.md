## TIP 盒仍有模型缺口

A 的来源盒是 S2/T11，B 是 S2/T12；默认移液/测密度 TIP 编号分别是 1、2 和 3、4，编号错开。但是两个流程发给 S09 的取 TIP 工位编号都是 1，测密度放 TIP 工位是 2。

驱动 add_liquid_with_materials / measure_density_with_materials 原样透传 tip_box 资源，实际 PLC 操作按 tip_box_index / take_tip_box_index / tip_index 执行；没有在这里校验来源盒 UUID 与 S09 物理工位的对应关系，流程也没有把这两个来源盒搬到 S09 的步骤。因此只能确认树中盒子存在，不能据此确认 S09 的真实 TIP 可用性和盒身份对应正确。

这不是本次预检已经报出的阻塞，而是物料身份与实际设备工位之间尚未闭合的校验。物理联调前需要明确该映射及可用 TIP；模拟器传感器为真也不能代替物料身份验证。
